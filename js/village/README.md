# Горное село мастеров (регион `kubachi`)

Свободная прогулка по горному селу: амфитеатр террас, башня над облаками, площадь с поилкой, пекарня, мастерские
с блеском серебра, комната-сокровищница, крыша-терраса, западный уступ, родник, парковка и выезд на серпантин.
Жители — зверята (10 говорящих + молчаливый голубь), у каждого 2–4 короткие реплики с проверенными фактами.

Ванильный JS, Three.js r149, без сети, без фотографий и фототекстур (все текстуры рисуются на canvas).

## Поездка целиком (стенд `village.html?region=serpentine`)

**Волна 4 (стенд `village_w4.html`):** героиня за рулём; газ, тормоз и руль — только от игрока (`drive.touchInput`: палец слева —
руль, педали справа), машина сама не тормозит и не рулит; ограждений нет — у края мягкий щебень, с дороги не упасть; «🚪 Выйти»
медленнее ~11 км/ч, пройтись, «Сесть» на лавочку в 3 м, «🚗 Сесть за руль»; развилка за 54 м до ворот — ветка к отелю (`toHotel`).
Ниже — описание волны 3 (до ограждений и подруливания), оставлено для истории.

Край города (щит «Кубачи ↑ / Город ↓») → газ: машина сама держит дорогу на всех 6 шпильках → над облаками один раз
камера показывает село через долину → у последней шпильки кнопки «⭐ Посидеть: смотровая» (машина стоит, камера на лавочке,
FOV 58 → 16 за 2,6 с — кадр p3) и «Поговорить: тур» → ворота: выход `toVillage` срабатывает сам (облачная шторка) →
село, героиня у парковки, машина на стоянке → прогулка, жители, места → «🚗 Сесть в машину» (или «Дорога вниз») →
шторка → наверху серпантина у ворот, носом вниз → газ: вниз по всем шпилькам → у края города выход `toCity` → шторка и
карточка «Город» («Снова в горы» — опять к щиту). Управление: газ/тормоз справа, палец слева — руль (куда ехать),
WASD/стрелки + Shift/B — тормоз. Вниз машина тоже едет сама: подруливание `drive.js` берёт точку впереди по ходу носа.
Тормоз после остановки везёт машину назад — подпись педали тогда «назад» (`drive.brakeLabel()` → `'назад' | 'тормоз'`,
`drive.reversing`), иначе «тормоз».

Хуки поездки в `window.__village`: `drive()` (состояние машины и поездки), `teleportS(s, rev)`, `auto(thr)`, `act()`,
`act2()`, `sitRoad()`, `simDrive(sec, input, {until})` — физика 60 Гц без рендера, выходы срабатывают как в игре.
QA-хуки: `simCar({s, rev, mode: gas|rev|lockL|lockR|joyPerp|fuzz, steps, dt})` — машина без рендера и выходов (скачки s,
выезд кузова, застревание); `simWalk({start, seed, dt, steps, still, meshes})` — тот же `stepWalk` + камера со случайным
джойстиком (центр в коллайдере, перепады, отрыв, выход за проходимое, камера в доме / под землёй / за стеной).
Машина не застревает: газ упёрся дольше 1 с — сама сдаёт назад ~1 с (`drive.js`, кроме концов дороги).
Проверка: `scratchpad/integ/trip.js` (17 шагов: старт → смотровая → тур → село → пекарня → вниз → «Город» → старт).

## Интерфейс региона

```js
const h = VILLAGE.regions.kubachi.build({
  THREE, scene,              // обязательно
  named: true,               // по умолчанию VILLAGE.named !== false
  season: 'autumn',          // 'autumn' | 'winter'
  quality: 'low',            // 'low' — запечённый свет (MeshBasic + цвет вершин), без теней; 'high' — тун + тени
  mood: 'day',               // 'day' | 'evening' | 'fog' | 'winter' (зимой по умолчанию 'winter')
  clouds: true,              // море облаков внизу (облака на небе — всегда: день и вечер; зимой и в туман их нет)
});
```

Регион кладёт всё в одну группу `h.root` (`'village:kubachi'`), сам ставит `scene.fog` и `scene.background`
и возвращает прежние в `dispose()`. Свет (`h.lights.hemi`, `h.lights.sun`) — свой, внутри группы.

| Поле | Значение |
|---|---|
| `id`, `title`, `mapLabel` | `'kubachi'`; «Кубачи» / «Горное село мастеров» (по `named`) |
| `named`, `season`, `quality`, `buildMs` | что собрано и за сколько мс |
| `spawn` | `{x,y,z,ry}` — у парковки, лицом к площади |
| `carSpawn` | `{x,y,z,ry}` — место машины на парковке |
| `ground(x,z)` | высота земли (м); `groundInfo(x,z)` → `{y, kind}` (`square`, `strip`, `roof`, `yard`, `path`, `field`, `spring`, `road`, …) |
| `collide(x,z,r,y)` | разрешение столкновений круга радиуса `r` на высоте `y` → `[x, z]` (коллайдеры ниже/выше героини не мешают) |
| `rayHit(a,b)` | доля отрезка `a→b` (`{x,y,z}`) до первой коробки — для камеры «не в стену»: дома, края террас, а также `camColliders` (кроны, галереи на выносе, дома с ходибельной крышей, свод арки, вывески над головой, комната «метро», башня-восьмиугольник, стенки лестниц) |
| `path(x0,z0,x1,z1)` | A* по сетке 0,25 м с учётом ступеней ≤ 0,45 м → `[[x,z,y], …]` (точка каждые ~1,5 м) или `null` |
| `walkable(x,z)` | клетка проходима |
| `colliders` | массив `{type:'box', x,z,w,d,ry,y0,y1,id}` / `{type:'circle', x,z,r,y0,y1,id}` (дома, ограды, края террас, стволы) — для ходьбы |
| `camColliders` | коробки `{…, cam:true}` только для луча камеры (ходьбе не мешают; `rayHit` их уже учитывает) |
| `npcs` | жители (см. ниже) |
| `spots` | места-занятия (см. ниже) |
| `exits` | `{id:'toRoad'|'toCity', x,y,z,r,label,icon}` — выезд вниз на серпантин и «сесть в машину» |
| `camera` | `{views, near:0.1, far:1600, fogNear, fogFar}`; `views[id] = {pos, target, fov, aspect?, mood?}` |
| `update(dt, heroPos, camera)` | анимация: жители, беркут, лошадка, кошка, облака, блеск, вода, бельё, дым, снег; небо и хребты едут за камерой |
| `setMood(id)`, `mood()` | смена настроения (небо, свет, туман, вечерние окна) |
| `setClouds(on)` | море облаков |
| `feedCat()` | кошка с крыши пойдёт за героиней ~20 с |
| `places` | опорные точки: `tower`, `square`, `museum`, `bakery`, `spring`, `knoll`, `park`, `arch` |
| `stats()` | куски, треугольники, коллайдеры, жители, время сборки |
| `dispose()` | убрать группу, вернуть туман/фон, освободить геометрию, материалы и текстуры |

Камеры `p1…p5` повторяют пять опорных фото (кадр совпадает по композиции; `p1`/`p4` — издалека снизу длинным фокусом,
`p3` = смотровая серпантина, `p5` — с площадки башни; сравнение — `plan2/kubachi_vs_photos.png`), плюс `lane`, `square`, `roof_sunset`
(с `mood:'evening'`), `winter_overview`, `overview`, `spring`, `stair`, `tower_near`, `spyglass`, `tower_top`.

### Жители (`h.npcs[i]`)

`{ id, speaker, name, root, x, y, z, headY, talkR, lines: [строки], silent, hop() }`. `id` — speaker id для озвучки
(`badger`, `owl_keeper`, `eagle`, `roof_cat`, `pony`, `mtn_sheep`, `baker_bunny`, `spring_hedgehog`, `mouse`,
`granny_hedgehog`, `pigeon_metro`; `pigeon_arch` молчит). Голова сама поворачивается к героине ближе 4 м, моргание,
дыхание, свои мелочи (беркут кружит над башней, лошадка возит сено, кошка ходит по крыше). Дальше 46 м (60 м на high)
от героини или дальше 70 м (90 м) от камеры жители скрыты (беркут — дальше 240 м), обводка — только ближе 20 м.
Рост — как у зверей-жителей города (`js/world/actors.js`): барсук 1,17 м, сова 1,2, ёжики 1,1–1,14, мышка 1,0, зайка с ушами
1,5, лошадка 1,38 при героине 1,9 (масштаб — промежуточной группой `npcScale`, корень 1:1; `headY` уже в метрах с учётом роста,
`scale` — множитель). Без героини рядом — дыхание, лёгкое покачивание, иногда оглядываются, хвостики качаются.
**Разговор:** `npc.faceHero = сек` (как в городе: игра ставит при реплике) — житель плавно поворачивается к героине, потом
обратно к `ry0`; сидящие (барсук, бабушка, мышка, зайка, кошка) корпусом не больше `seatYaw` рад, остальное — головой;
лошадка на это время останавливается.

### Места (`h.spots[i]`)

`{ id, x, y, z, r, icon, label, action, level?: 'ground'|'top', seat?, ry?, view?, use(ctx) }`.
`level:'top'` — места на верхней площадке башни (героиня там после `tower`). `use(ctx)` делает побочный эффект в самом
регионе (например, зайка подпрыгивает) и возвращает описание для игры:

| `kind` | Что делает игра |
|---|---|
| `sheet` | открыть лист занятия `VILLAGE.activities(named)[activity]` (пекарня, мастерская, музей, сокровищница, резные камни) |
| `sit` | посадить героиню на `seat` (повернуть на `ry`), включить камеру `view`, при `mood` — сменить настроение |
| `view` | показать вид `view` (подзорная труба) и реплику `VILLAGE.eventLine(event)` |
| `teleport` | облачная/тёмная шторка `fade`, перенести героиню в `to` на уровень `level` (башня вверх/вниз) |
| `drink` | «Ух, холодная!», реплика `npc` из `eventLine(event)` |
| `talk` | начать разговор с жителем `npc` |
| `toast` | короткая подпись |

Дополнительно: `npc` — кто откликается, `event` — id события в `lines.js`, `flag` — что запомнить (`bread`, `pendant`),
`collect:'stones'` — счётчик трёх резных камней. Стенд (`useSpot` в `village.html`) — готовый пример всех веток.

## Встраивание в игру

1. **Загрузка/выгрузка.** Регион живёт в той же сцене и рендерере, что и город. Переход — облачная шторка (как
   `fade()` в стенде): закрыть экран → `World.pause()`/`release()` города → `kubachi.build({...})` (1–2 с на телефоне;
   рисуем шторку до первого `update`) → `camera.far = h.camera.far`, `near = h.camera.near` → поставить героиню в
   `h.spawn` → открыть шторку. Уход: шторка → `h.dispose()` → вернуть камеру и город. Регион не трогает рендерер,
   размер холста, тени (`renderer.shadowMap` включает игра при `quality:'high'`).
2. **Кадр.** `h.update(dt, heroPos, camera)` раз в кадр. Ходьба: `[x, z] = h.collide(nx, nz, 0.3, y)`, затем
   `y = h.ground(x, z)`; если подъём больше ~0,7 м — шаг не делать (края террас уже закрыты коллайдерами).
   Камера (как `updCamera` в `village.html`, проверено QA): идеальная точка за спиной → не ниже `ground + 1,2` →
   рельеф между головой и камерой (точки 0,5 и 0,75 луча) — поднять, не больше 3,5 м → `t = rayHit(голова, камера)`;
   `t < 1` — придвинуть к `t − 0,07`; если ближе 1,2 м («спиной к стене») — камера над плечом на +3,2 м, чуть впереди
   героини; после сглаживания ещё раз `ground + 0,6` и `rayHit` (сглаживание не протаскивает камеру сквозь дома).
3. **Разговоры.** Кнопка «Поговорить» у жителя ближе `talkR`: `G.say(npc.lines.map(text => ({ who: npc.speaker, text })))`
   — по одной реплике за раз или все подряд. Для пузырька над головой: точка `npc.root.position + headY`.
   Можно брать тексты напрямую: `VILLAGE.linesFor(named)[id]` → `[{who, text}]`.
4. **Места → листы игры.** `const d = spot.use({ named })`; для `kind:'sheet'` — `VILLAGE.activities(named)[d.activity]`
   (`title`, `text[]`, `menu[]`, `steps[]`, `reward`, …) в обычный лист/карточку игры. Для `sit`/`view` — свои
   `views` региона: `{pos, target, fov}` в макро-координатах.
5. **Голоса.** Все реплики — литералы `{ who, text }` в `js/village/lines.js`; `tools/voice_lines.js` их уже находит
   (44 строки с `who` из `js/village/lines.js`, 11 говорящих, плюс варианты `n:` для `named:false`). Новым speaker id нужны пресеты в `CAST`
   (`tools/voice_build.py`, этот файл здесь не правился): описание голоса — в `VILLAGE.SPEAKERS[id].voice`.
6. **Название.** `VILLAGE.named = false` (или `build({named:false})`, `linesFor(false)`, `activities(false)`) —
   «Горное село мастеров», без названия села и этнографических слов (`VILLAGE.BANNED_NEUTRAL` — список для проверки).
7. **Серпантин.** Выход `toRoad` (62, 0, −10) стыкуется с регионом `serpentine`; общие данные —
   `VILLAGE.regions.kubachi.data` (`P`, `polar`, `OPP`, `road()`, `exitToRoad`, `TOWER`, `PARK`).
   Село с дороги: `VILLAGE.regions.kubachi.distant(THREE, season, { named })` — **настоящее село** (тот же код, режим
   `build({ far: true })`: дома, башня, террасы, деревья, чаша склона под селом; без жителей, ходьбы, фона, света и
   мелочи; свет запечён, издалека без атласа; ≈ 50 тыс. тр., 7 вызовов, `userData.dispose()`); `{ full: false }` — старые
   коробки (1 вызов). Серпантин при этом опускает свою грубую «чашу села» под рельеф села (`distantFull`).
   Обратно: фон села берёт склон напротив из `VILLAGE.regions.serpentine.groundCut(x, z)` (рельеф региона дороги с
   врезкой полотна) и ленту дороги из `serpentine.distant(THREE, season, { w, col, wall, skirt })` — с башни (p5) серпантин
   лежит ровно там, где по нему ехали.

## Координаты

Метры, x — восток, y — вверх, z — юг, y = 0 — площадь. Центр амфитеатра `C = (0, 96)`,
`P(r, φ) = (r·sinφ, 96 − r·cosφ)`; ряд k: пол `−4,8·(k+1)`, крыша ряда k+1 — улица ряда k. Башня (−11,2; −15,4), Ø 7,4 → 6,8 м (по p1/p4),
низ 5 м, площадка 16,9 м, вокруг неё 4 дома-«шапка» (`tower_ring`). Площадь (12,3; −6,3), парковка (26,7; −4,5), родник у (5; 64) на −43,2 м.
Башня (polish 14.10, по p1/p4): тёсаный охристый камень рядами с мягкими пятнами тона, пояс-карниз на 36 консолях (выступ
0,22 м, тёмная тень снизу), парапет 0,64 м и 20 крупных зубцов 0,6 м (просветы читаются и со смотровой), 6 окон вразбежку —
с любой стороны видно ≈ 3 (`TOWER.windows`, азимут/высота). Коллайдеры и коробки камеры башни прежние (радиусы те же),
беркут сидит на зубце к ЮЗ (−45°). Склон под селом (видно со смотровой): `lowerQuarter()` — справа дома, редеющие книзу,
слева террасы со стенками и рядами осенних плодовых деревьев; всё за краем ходьбы, без коллайдеров.

## Бюджет

Одна полоса-атлас 512×1024 на все стены/крыши/камень, кусок 32 м — один вызов. Повторяющиеся детали (окна, листы
кровли, трубы, кроны, стволы, камни) — `K.merged(geo, mat, list, o)`: одна обычная сетка с запечёнными матрицами и
цветом (окна — `K.glazMatV`, плитка и тёплый свет — атрибуты вершин). `K.instanced` остался, но на программном рендере
инстансы с атрибутами дороги: замер в swiftshader — окна-инстансы съедали 30–37 % кадра села, склеенные — ≈ 3 %.
В серпантине так же склеены кроны, стволы, камни, пучки травы и столбики (`bakeInst`).

## Волна 6++: ближний рельеф снова виден, ничего не висит в воздухе (16.10)

Автор (айфон, релизная сборка): «щель между горой и дорогой осталась», «по дороге деревья висят в воздухе как будто баг».
- **Корень**: в `serpentine.js` строка `root.add(m); meshes.near = m;` для сетки `terrainNear` оказалась в хвосте `//`-комментария
  (с волны 6) — ближний рельеф (24 м по обе стороны дороги) не попадал в сцену: виден был только грубый дальний, опущенный
  у полотна на 3 м (щель у скалы, «пустота» за кромкой), а деревья и камни стояли на невидимой земле. Исправлено в 95e7760;
  та же ошибка была в цвете скалы (`const ln = …; if (ln > 0.62) cA.lerp(cLichen …)` внутри комментария — пятна лишайника
  и инея не рисовались) — вынесено на свою строку. Правило: код после `//` на той же строке не пишем.
- **ground() у скалы**: брал максимум по всем отрезкам в 12 м до их прямых — на внутренней стороне поворотов (каждый нос
  отрога) скала выходила выше на 5–10 м; по ней ставились камни, трава, кусты, столб щита, к ней липла камера. Теперь профили
  рядов скалы считаются до рельефа (`cliffAt`, `CPE/CPH`), меш скалы строится из них же, `ground()` берёт ближайший отрезок
  и настоящую поверхность (верх; под навесом — навес). Проверка «на полотне» — по ближайшему отрезку основной дороги и ветки
  и по настоящему расстоянию (у конца отрезка e — лишь проекция: трава за краем на внешней стороне поворота висела на высоте
  дороги). Камни со стороны скалы — осыпью у подошвы, трава — не на крутой стенке, кусты — только на канте.
- **Ближняя сетка** (`shaped`): полотно и диагональ клетки за краем — не выше полотна − 0,22 (по ближайшему отрезку; без
  «плиток» травы поверх дороги в кармане смотровой и у мостика); обочина (1,25 м + клетка) не ниже полотна − 0,6 (под краем
  нет щели); за подошвой скалы рельеф уходит под камень: до первого ряда стенки и ещё клетку — ровно на 0,12 м ниже обочины,
  дальше — под стенкой (пропала «пила» у подошвы на high). Мостик: овраг под полотном только в пролёте арки (±2,8 м),
  у концов мостика — обочина; стенки мостика — ленты по краю полотна, верх вровень с дорогой (прямая 13-метровая плита на
  крутом повороте торчала над полотном на 0,9 м).
- **Шов ближней и дальней сетки**: юбка ближней сетки — с нормалью и цветом своего узла (светлые зубцы пропали) и глубже

### Волна 6++ (доводка после проверки): шов сеток, мостик, торцы скалы (16.10)
- **Зубчатый шов ближней и дальней сетки** (виден с дороги у смотровой, на 600–640 м, зимой — белые «плиты» над серым):

  ближняя сетка низко (под камнем), и точный проход тянул туда дальние треугольники. Теперь: дальняя — природный рельеф,
  под ближнюю её уводит только точный проход; узел, у которого и все соседи под стенкой, держит дальнюю лишь под нижним
  краем стенки; край ближней сетки ложится на дальнюю (+4 см) и плавно уходит к ней за 6 м (`FADE_M`, `NBD`), цвет
  и нормаль этой полосы — как у дальней под ней; юбка — 2,5 м (было 12). На high дальний рельеф светится той же рампой,
