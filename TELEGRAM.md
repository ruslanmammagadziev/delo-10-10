# Как выложить игру и сделать из неё Telegram Mini App

Игра — это статичные файлы. Нужен хостинг с HTTPS и бот в Telegram, который открывает этот адрес.

## 0. Что выкладывать
**Всё открыто сразу** (решение автора, 15.10): город, велосипед, собачка, машина, поездка в Кубачи, отель, зиплайн, параплан, спорт — `CONFIG.UNLOCK` в `js/config.js` (`'always'`). Вернуть открытие по датам — вписать даты обратно (было: собачка 2026-11-07, велосипед 2026-11-14, машина 2026-11-21).

Папка `site/` — готовая сборка «её версии» (даты открытия по календарю):
- `site/index.html` — игра одним файлом (prod);
- `site/cover.png` — превью ссылки;
- голоса героев **выключены** (решение автора 15.10: `VOICES: false` в `js/config.js`) — реплики только текстом, папки `site/voice/` нет. Включить обратно: `VOICES: true` и пересобрать (папка `voice/` с записями лежит в репозитории).


Пересобрать `site/` из исходников (нужны Python 3 и Node.js):
```
npm i terser
python3 tools/build_single.py --prod --out site/index.html   # кладёт рядом и site/voice/
cp cover.png site/
```

## 1. Хостинг
**Сейчас игра выложена на Vercel: https://delo-10-10-seven.vercel.app/** — проект `delo-10-10`, подключён к этому репозиторию: каждый `git push` в `main` выкладывает папку `site/` (это задаёт `vercel.json`).

Другие варианты (если когда-нибудь понадобятся):
**Важно:** репозиторий держим **приватным**: в исходниках есть служебные списки и материалы, которые не для чужих глаз.
- **GitHub Pages** бесплатно работает только для **публичных** репозиториев (для приватных нужен GitHub Pro). Поэтому этот способ не подходит.
- **Cloudflare Pages / Netlify / Vercel** — бесплатно и с приватным репозиторием:
  1. Войди через GitHub и выбери репозиторий `delo-10-10`.
  2. Build command: **оставить пустым**. Output / Publish directory: **`site`**.
  3. Deploy. Получишь адрес вида `https://delo-10-10.pages.dev` (Cloudflare) или `https://delo-10-10.netlify.app`.
  4. Дальше каждый `git push` в `main` обновляет сайт сам.
- Совсем без репозитория: **Netlify Drop** (app.netlify.com/drop) — перетащить содержимое папки `site/`.

## 2. Вписать адрес в игру
- `js/config.js`:
  - `GAME_URL: 'https://…/'` — адрес сайта;
  - `MINIAPP_URL: 'https://t.me/<бот>/<короткое_имя>'` — после шага 3;
  - `AUTHOR_NAME: '…'` — для титров.
- `index.html`: заменить `SITE_URL` на адрес сайта (превью ссылки).
- Пересобрать `site/` (шаг 0) и закоммитить.

## 3. Бот и Mini App в Telegram
1. Открой **@BotFather** → `/newbot` → имя (например «Дело 10/10») → username (оканчивается на `bot`). Токен никому не показывай и в код не клади: он здесь не нужен.
2. `/newapp` → выбери бота → название, описание, картинка 640×360 (можно взять кадр из `cover.png`), GIF — пропустить → **Web App URL** = адрес сайта → короткое имя (например `delo`).
   Получишь ссылку **`https://t.me/<бот>/delo`** — по ней игра откроется прямо в Telegram.
3. (Можно) кнопка в чате бота: `/mybots` → бот → **Bot Settings → Menu Button** → URL сайта, текст «Играть».
4. (Можно) `/setdescription` и `/setuserpic` — описание и аватар бота.

Игра уже понимает Telegram: подстраивается под окно, сохраняет прогресс в облако Telegram, работает и как обычная ссылка в браузере.

## 4. Обновления (новые серии)
- Пересобрать `site/`, сделать `git push` — хостинг обновится сам, ссылка `t.me/<бот>/delo` остаётся прежней.
- Если Telegram показывает старую версию — закрыть Mini App и открыть заново (или подождать пару минут).

## 5. Проверка перед отправкой
- Открыть ссылку на своём телефоне в Telegram: звук, город, сохранение (закрыть и открыть — прогресс на месте).
- `python3 tools/scan_words.py site/index.html` — в сборке не должно остаться `TODO`.
